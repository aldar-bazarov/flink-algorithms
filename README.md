# Flink Algorithms

Набор Python entry point скриптов для потоковых алгоритмов Apache Flink.

## Структура

```text
algorithms/                 Алгоритмы, которые запускает FlinkScriptManager
algorithms/utils/           Общий PyFlink каркас и вспомогательные функции
examples/                   Примеры алгоритмов для обучения
tests/                      Локальные тесты
tools/                      Скрипты для разработки и подготовки шаблонов
docs/                       Документация
.vscode/                    Настройки редактора
```

Файлы конфигурации и командные скрипты (`pyproject.toml`, `requirements-dev.txt`,
`check.sh`, `setup_local.sh`) остаются в корне.

Имена алгоритмов сохранены: платформа может ссылаться на них по имени файла.

## Разработка

Первичная установка и ежедневные команды описаны в
[инструкции локальной разработки](docs/local-development.md).

Для локальной проверки выполните из корня проекта:

```bash
./check.sh
```
